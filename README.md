## Quick Start

### Prerequisites

- **Node.js** 18.0 or later
- **npm** or **yarn** package manager


### Installation

1. **Clone the repository**

```shellscript
git clone https://github.com/mohamededdahby/portfolio-website.git
cd portfolio-website
```


2. **Install dependencies**

```shellscript
npm install
# or
yarn install
```


3. **Set up environment variables**

```shellscript
cp .env.example .env.local
```

Update `.env.local` with your configuration:

```plaintext
NEXT_PUBLIC_DEVELOPER_NAME="Your Name"
NEXT_PUBLIC_DEVELOPER_EMAIL="your.email@example.com"
CONTACT_EMAIL_TO="your.email@example.com"
# Add other variables as needed
```


4. **Run the development server**

```shellscript
npm run dev
# or
yarn dev
```


5. **Open your browser**
Navigate to [http://localhost:3000](http://localhost:3000)

## Customization

### **Personal Information**

Update your details in the environment variables or directly in components:

- `components/hero.tsx` - Hero section content
- `components/about-me.tsx` - About section details
- `components/contact.tsx` - Contact information


### **Styling**

- **Colors**: Modify the color scheme in `tailwind.config.ts`
- **Fonts**: Update font families in `app/layout.tsx`
- **Animations**: Customize animations in component files


### **Content**

- **Projects**: Update project data in `app/projects/page.tsx`
- **Skills**: Modify skills in `components/about-me.tsx`
- **Services**: Update services in `components/services.tsx`
